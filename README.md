### Запуск проекта
### 1. Клонирование репозитория

```bash
git clone <URL-репозитория> chessLearningPlatform
cd chessLearningPlatform
```

```bash
git checkout develop
git pull origin develop
```

### 2. База данных PostgreSQL

Создание базы данных (через pgAdmin делал):

```sql
CREATE DATABASE chess_platform;
```

### 3. Backend

```bash
cd backend
```

Установка зависимостей, миграция и демо-данные:

```bash
npm install
npm run migrate  создаёт и обновляет структуру БД
npm run seed:demo заполняет БД тестовым содержимым
```

Запуск сервера:

```bash
npm run dev
```

Сервер API: **http://localhost:5000/api**

### 4. Frontend

В **новом** терминале:

```bash
cd frontend
```

```bash
npm install
npm start
```

При ошибке конфликта зависимостей:

```bash
npm install --legacy-peer-deps
```

Приложение откроется в браузере: **http://localhost:3000**

## Полезные команды (backend)

| Команда | Описание |
|------|--------|
| `npm run migrate` | Миграции схемы БД |
| `npm run seed:demo` | Полный набор тестовых данных |
| `npm run seed` | Только три учётные записи |
| `npm run seed:themes` | Тематики курсов (дебют, миттельшпиль и др.) |
